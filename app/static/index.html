Good to know

Does it remove a watermark from the pixels?

No. It looks for a public media stream that TikTok exposes without the branded watermark. If TikTok only exposes a watermarked stream, the site says so.

Does it work with private videos?

No. The backend does not use accounts, session cookies, or private-access bypasses.

Why can a link fail sometimes?

TikTok changes its delivery system and rate limits servers. Keeping the extractor current is part of operating this type of service.

Are videos stored permanently?

No. Downloads are created in a temporary server folder and deleted after the response is sent.
