Snipivo TikTok + Instagram V1.4

Fixes in this release:
- One-tap download flow: after the user chooses Clean / MP4 / MP3, Snipivo prepares the file and automatically hands it to the browser download manager.
- Removes the extra "Ready — tap to save" step on iPhone/iPad.
- Applies to both TikTok and Instagram download options.
- Keeps prepared download URLs valid briefly so Safari/Chrome can retry or use range requests without getting a false expired/used error.
- Preserves V1.3 cache busting and no-cache frontend headers.
- Bumps frontend/backend troubleshooting version to 1.4.0.

Expected flow:
Paste link -> resolve -> choose format once -> Preparing -> browser download starts automatically.
