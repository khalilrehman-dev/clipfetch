Snipivo TikTok + Instagram V1.6

New in this release:
- Adds visible media-type badges and clearer preview labels after link resolution.
- Shows only available video-quality choices (Best, 1080p, 720p when exposed by the source).
- Adds MP3 bitrate choices: 128, 192, and 320 kbps.
- Shows approximate file size when source metadata is available.
- Carousel results clearly show image count before ZIP download.
- Download preparation messaging now includes the selected quality and elapsed time.
- Prepared-download API returns the actual prepared file size when available.
- GA4 events now include selected video quality / audio bitrate.
- Preserves V1.5 image/carousel support and the V1.4 one-click automatic handoff.
- Preserves no-cache frontend delivery for Safari and other mobile browsers.

Expected flow:
Paste link -> resolve -> preview + platform/media type -> choose quality -> choose download -> Preparing -> automatic download.

Notes:
- File-size values shown before download are estimates based on metadata and can differ from the final file.
- A 320 kbps MP3 output cannot add detail that does not exist in the source audio; it controls the MP3 encode bitrate.
- Quality options are restricted to what the public source exposes.
