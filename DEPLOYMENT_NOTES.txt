Snipivo TikTok + Instagram V1.5

New in this release:
- Adds best-effort public image support while preserving the stable V1.4 one-click download flow.
- Instagram single-image posts: Download image.
- Instagram supported image carousels: Download all images as ZIP.
- TikTok supported photo-mode/slideshow posts: Download image(s), with multi-image posts packaged as ZIP.
- Automatic media-type detection: video / image / carousel.
- New GA4 image-resolution and image-download events.
- New SEO pages for Instagram photos and TikTok photos.
- Sitemap updated.
- Keeps V1.4 cache busting and no-cache frontend delivery.

Expected flows:
Video: Paste link -> resolve -> choose MP4/MP3/Clean -> Preparing -> automatic browser download.
Image: Paste link -> resolve -> Download image -> Preparing -> automatic browser download.
Carousel: Paste link -> resolve -> Download all images -> ZIP -> automatic browser download.

Important:
Image support is best effort because TikTok/Instagram may not expose every public image post to an unauthenticated server. Snipivo does not use user passwords/cookies to bypass login gates.
